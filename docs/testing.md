## Запуск тестов

### Unit тесты
```bash
npm run test-unit
```

### Unit тесты с покрытием
```bash
npm run test-coverage
```

### Unit тесты в watch режиме
```bash
npm run test-unit-watch
```

### Запуск конкретного файла
```bash
npm run test-unit -- app/main/services/__tests__/audioSessionService.test.ts
```

## Интеграционные тесты

Интеграционные тесты находятся в `app/main/__tests__/integration/audioRouting.test.ts`.

**Важно:** Интеграционные тесты требуют:
- Установленного SoundVolumeView.exe
- Установленного VB-Cable
- Windows платформы

Эти тесты автоматически пропускаются если SoundVolumeView не найден.

## Рекомендации

1. **Для CI/CD:** Используйте `npm run test-unit` - он запускает только unit тесты без интеграционных
2. **Для локальной разработки:** Используйте `npm run test-unit-watch` для автоматического перезапуска
3. **Для проверки покрытия:** Используйте `npm run test-coverage` и откройте `coverage/index.html`

## Известные ограничения

1. Некоторые тесты SVVLocator требуют реальной файловой системы или более сложных моков
2. Интеграционные тесты требуют реального SoundVolumeView.exe
3. Тесты работают только на Node.js окружении (не требуют Electron)
